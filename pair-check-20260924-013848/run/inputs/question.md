# Analyze a small synthetic return series

Using the authorized returns.csv file, investigate how arithmetic
average return differs from compounded investment growth.

Start with wealth equal to 1. Calculate:
- The wealth after each period, including the initial wealth.
- The cumulative compounded return.
- The arithmetic mean return per period.
- The maximum peak-to-trough proportional drawdown, expressed
  as a nonnegative loss magnitude.

Explain the difference between average return and cumulative growth.
These are five artificial observations, not evidence about a market
strategy. Do not annualize or make profitability claims.

packages, or modify the agent implementation.

report. Choose appropriate artifact filenames and follow the agent's
